---
description: Перегенерировать все артефакты из TypeSpec-спецификации одной цепочкой
---

Обнови все артефакты, сгенерированные из спецификации (команда уже запущена, вывод ниже):

!`npm run spec:generate`

Дальше сделай следующее:

1. Если генерация упала — диагностируй ошибку, исправь её (правки только в исходниках: `spec/*.tsp`, конфиги) и перезапусти `npm run spec:generate`.
2. Покажи `git status --short` и перечисли, какие артефакты изменились: `spec/output/openapi.yaml`, `apps/web/src/api/schema.d.ts`, `apps/server/src/api/schema.d.ts`.
3. Если сгенерированные файлы изменились, а правок контракта (`spec/*.tsp`) в этой сессии не было — предупреди и разберись, откуда разница, прежде чем что-то делать.
4. Коммиты не делать — артефакты попадают в отдельный коммит вместе с правками контракта.
