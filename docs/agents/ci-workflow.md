# CI и git-история (OpenCode в GitHub Actions)

## Как работает экшен
Экшен OpenCode V1 создаёт ветку, ждёт ответ агента, проверяет дерево (`branchIsDirty`).

- Дерево чистое, HEAD сдвинулся → агент уже закоммитил. Экшен пушит ветку и открывает PR (`pushToNewBranch`/`pushToLocalBranch` с `commit=false`).
- Дерево грязное → экшен сам делает коммит. Сообщение берётся не из ответа агента, а отдельным вызовом `summarize` («Summarize the following in less than 40 characters»). Из-за лимита в 40 символов теряются `type(scope):`, тело и `Closes #NN`.

## Правила для агента
1. `git add` и `git commit` делать самому. Обе команды разрешены в `.opencode/opencode.jsonc`.
2. Коммит — по Conventional Commits. Первая строка `type(scope): ...`, пустая строка, тело с описанием что и почему, последняя строка `Closes #NN` или `Часть тикета #NN`.
3. После коммита дерево должно быть чистым. Недокоммиченный/неотслеживаемый мусор экшен закоммитит своим резюме с неканоничным сообщением.
4. Ветку не переключать. Со своей веткой экшен корректно определит, что PR создан агентом.
5. **Финальный ответ** — только первая строка коммита (`feat(web): ...`, `fix(server): ...`). Без «Готово.», списков, кавычек, markdown, точки в конце. Экшен передаст её в `summarize` и сделает заголовком PR.
6. Историю не переписывать. `--amend`, `rebase`, `reset`, `branch -f`, `update-ref`, `push --force` запрещены.

## Ветки
- Если работа начинается на `main` — сначала `git checkout -b feat/<краткий-слаг>` или `fix/<краткий-слаг>`. Слаг латиницей, по смыслу.
- Если есть тикет — допустимо `opencode/issue<N>-<YYYYMMDDHHMMSS>` (как делает экшен).
- В CI (`GITHUB_ACTIONS=true`) ветку создаёт сам экшен. Создавать свою ветку в CI — вредно: экшен увидит подмену и ничего не запушит.

## Почему запреты такие
- `git push` запрещён агенту — пуш делает экшен.
- `--amend/rebase/reset` запрещены, т.к. переписанный tip не будет запушен (`non-fast-forward`) в эфемерном раннере и правки потеряются.
- `gh pr merge/close` оставлены человеку. `gh issue *` разрешён (чтобы закрывать тикет строкой `Closes #NN` в коммите).
