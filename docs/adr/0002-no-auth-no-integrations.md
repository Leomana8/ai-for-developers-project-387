# Без авторизации, кабинетов и внешних интеграций

Проект сознательно строится без авторизации, личных кабинетов и интеграций с внешними
календарями. Единственный сценарий — Владелец календаря публикует время, Пользователь выбирает
Слот и записывается.

Это осознанное «нет» с неочевидным следствием: без аккаунтов пока не определено, кому
принадлежит Встреча и как Владелец календаря узнаёт, кто именно записался. Добавление
авторизации позже — дорогое изменение, затрагивающее всю модель данных, поэтому решение
зафиксировано явно, чтобы его не «починили» по умолчанию.
