# SPA-навигация через React Router

Роутера в проекте не было — `App.tsx` был единственным экраном. Мы добавили `react-router-dom`
и собираем маршруты через `createBrowserRouter` + `RouterProvider`: `/` — главная, `/book` —
запись, `/health` — диагностика, `*` — редирект на главную.

Впереди несколько экранов (запись, подтверждение, сторона Владельца календаря), поэтому
клиентская навигация нужна уже сейчас. Решение трудно откатить: на маршруты завязаны ссылки и
копирайт, а самописный роутер пришлось бы переписывать на втором экране.

## Considered Options

- **Самописное переключение через состояние / `window.location`** — отвергнуто: переписывать при
  добавлении второго-третьего экрана, нет истории браузера и глубоких ссылок.
- **Обычные `<a href>` с полной перезагрузкой** — отвергнуто: бэкенд не раздаёт SPA-маршруты, теряется
  состояние приложения на каждом переходе.
- **`react-router-dom`** — выбрано: стандарт для React SPA, поддерживает глубокие ссылки и
  загрузчики данных на будущее.
